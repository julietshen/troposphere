# Introduction

`troposphere` is a standalone AT Protocol labeler service. It is a self-hostable
alternative to [Ozone](https://github.com/bluesky-social/ozone)'s label emitter: any
moderation backend drives it over a simple authenticated API, and it signs labels and
serves them to the atproto network through the standard `subscribeLabels` firehose and
`queryLabels` endpoint.

Ozone bundles two things: a moderation console with its own data model, and the machinery
that signs and publishes labels. `troposphere` is only the second half. That makes it
usable by anyone running their own moderation workflow, without adopting Ozone's console
or database.

It is built on the maintained `@atproto/*` primitives (`@atproto/crypto`,
`@atproto/xrpc-server`, `@atproto/common`), not on a single vendor's stack.

## Who this is for

- A project on the AT Protocol that needs to publish moderation labels and wants to own
  the signing key and the label stream.
- A team that already has a moderation backend (a queue, a rules engine, human reviewers,
  a classifier) and just needs the atproto-facing labeler piece.
- Anyone evaluating an alternative to running Ozone for labeling.

[Coop](https://github.com/roostorg/coop), ROOST's open-source trust and safety platform,
is the reference driver, but nothing here depends on Coop. The label-emit API is a plain
authenticated HTTP endpoint that any backend can call.

## What it does today

- Signs labels with a secp256k1 key, verifiable against the labeler's DID.
- Serves `com.atproto.label.queryLabels` (public HTTP).
- Serves `com.atproto.label.subscribeLabels` (WebSocket firehose) with cursor backfill and
  a live tail.
- Exposes `POST /admin/labels`, a bearer-authenticated API to create and negate labels.
- Accepts `com.atproto.moderation.createReport` from any AT Protocol AppView, stores each
  report, resolves the reported subject to its content, and optionally forwards it to your
  backend.
- Enforces takedowns and restores on your own PDS via `POST /admin/enforce`, alongside labeling.
- Persists labels and reports in Postgres, with a monotonic sequence for firehose cursors.

## What it does not do

`troposphere` is the labeler and enforcement arm, not the review console. It does not decide
what to label or take down; a backend does that and calls the APIs. [Coop](https://github.com/roostorg/coop)
is the reference console for this project (the review queue, reviewer roles, and event history
that Ozone's UI would otherwise provide). Identity provisioning helpers and multi-tenant
operation are on the [roadmap](./roadmap.md).
